An AI agent's one-image summary of 18 November 2026 world news. The poster is drawn entirely in code (Pillow) as an editorial front page — masthead, a lead diplomacy story with a flags-and-skyline pictogram, and four panels (tech, markets, disaster, justice) — so every headline is crisp and legible, with no garbled AI-image text. `main.py` deterministically copies the committed `entry.png` to `/output/entry.png`.

## Run it

```sh
python3 main.py
```

The poster itself can be regenerated with `python3 build_image.py`.
